# Product

## Vision
We believe the future of software development is **more work in parallel** instead of one slow queue, with **people and agents playing to their strengths, working both calmly and deliberately** across many threads. This only works when both people and agents have a **shared understanding** of the **current state**; **what is already decided**, **what is still uncertain**, and **when a person needs to weigh in**, so that **cognitive ownership** remains with the people. **Agentic Parallelism** should add **leverage**, not **noise**.

**We strive to meets developers where they are**: editors, repos, and tools; **one repo or many**; **greenfield or legacy**; inside the **repo you ship** or an **accompanying project repo** when the codebase is not ready for team-wide tooling. **Progressive mastery** means **starting simple** and **adding structure as payoff shows**. You can move from **trying agents** toward **meaningful parallelism** in **small steps** that build confidence, without a **big-bang overhaul** of the codebase for the harness sake.

We believe people and agents can interact purely via **Git, markdown and minimal config** which acts as the **system of record**: human readable in a **browser** (e.g. GitHub) with no new servers, **LLM-friendly** by shape. The **Kira CLI** adds **deterministic, repeatable** workflows for speed and precisions token usage. It **accelerates** collective knowledge, as history accrues, **mutual learning** deepens **shared understanding**, so fast paced parallel work does not leave people **in the darkness** of context buried deep in the memory of machines.
